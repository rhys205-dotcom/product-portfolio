# Product Portfolio

Source for [dowsall.com](https://dowsall.com), my personal product portfolio.

The site presents selected work across payments, regulated financial services, SaaS and applied AI. It is designed to show the product decisions, delivery constraints and evidence behind the outcomes—not to duplicate a full CV.

## Positioning

- Product Manager / Product Owner
- Payments and regulated financial services
- Finance SaaS, integrations and digital self-service
- Business analysis as a core delivery capability
- Applied AI with traceability and human oversight

LinkedIn is the source of truth for employers, titles and dates. The portfolio provides deeper case-study context.

## Selected work

- Scaling digital payments and improving financial workflows at PlotBox
- Designing and validating a one-way NetSuite journal-export workflow with customer-managed mappings and audit safeguards
- Delivering PSD2 Strong Customer Authentication and digital banking journeys at Avant Money
- Rolling out consent management across seven public websites
- Building an [AI Product Discovery Assistant](https://dowsall.com/discovery-assistant) that keeps source evidence and human review visible

## Technology

The site is intentionally lightweight:

- Semantic HTML
- Responsive CSS
- Vanilla JavaScript
- No framework or runtime dependencies
- Hosted on Cloudflare Pages through GitHub deployment

This keeps the portfolio fast, accessible and straightforward to maintain.

## Development approach

The product direction, professional examples and editorial decisions are my own. AI-assisted tools have supported implementation, review and iteration.

The public Discovery Assistant uses synthetic data and a pre-generated sample analysis. It does not send visitor data to a model or server. The separate local prototype can analyse an uploaded CSV using an LLM.
